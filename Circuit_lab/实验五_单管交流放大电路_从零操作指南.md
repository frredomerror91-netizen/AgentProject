# 实验五：单管交流放大电路

> 本文依据《实验五 实验指导书》和《实验五-数据记录页》整理。目标是让第一次做此实验的人能够完成：预习、接线、调试、测量、数据处理、波形记录和报告撰写。

## 1. 实验要回答什么问题

本实验研究一个 NPN 三极管 9013 构成的共发射极交流电压放大电路，重点观察：

1. 如何把三极管调到合适的静态工作点（Q 点）。
2. 静态工作点改变后，为什么会出现饱和失真或截止失真。
3. 发射极旁路电容 `Ce` 对电压增益的影响。
4. 负载电阻 `RL` 变小时，电压增益如何变化。
5. 如何使用信号发生器、示波器、直流稳压电源和万用表完成测量。

## 2. 先建立整体认识

### 2.1 电路结构

按指导书图 5-3 搭建分压偏置式共发射极放大器，主要元件和典型值如下：

| 元件 | 典型值/设置 | 作用 |
|---|---:|---|
| 三极管 | 9013，NPN | 放大元件 |
| `VCC` | `+12 V` | 直流电源 |
| `Rc` | `2.4 kΩ` | 集电极负载 |
| `Re` | `1 kΩ` | 发射极直流负反馈 |
| `Rb1`、`Rb2` | 各 `20 kΩ` | 分压偏置网络 |
| `Rp` | `100 kΩ` 可调 | 调节基极偏置、改变 Q 点 |
| `C1` | `10 μF` | 输入耦合，隔离输入直流 |
| `C2` | `10 μF` | 输出耦合，隔离输出直流 |
| `Ce` | `47 μF` | 发射极交流旁路；可断开比较 |
| `RL` | `1 MΩ`、`10 kΩ`、`1 kΩ` | 改变负载条件 |

电容为有极性电解电容：正端按图接在较高直流电位一侧。`C1` 的正端朝向三极管基极，`C2` 的正端朝向集电极，`Ce` 的正端接发射极。

### 2.2 信号路径和相位

输入交流信号经 `C1` 进入基极，集电极输出经 `C2` 送到负载。共发射极电路的电压增益为负，因此输出交流波形与输入反相（相位差约 `180°`）。

### 2.3 Q 点为什么重要

三极管是非线性器件。要得到尽可能大的、不失真的正弦输出，必须让 Q 点位于放大区中间附近。

- Q 点过低：`IC` 小、`UCE` 大，输入负半周容易使三极管截止，出现**截止失真**。
- Q 点过高：`IB`、`IC` 大、`UCE` 小，输入正半周容易使三极管饱和，出现**饱和失真**。
- `Rp` 是调节 Q 点的主要元件。

当 `VCC=12 V` 时，最佳位置的目标是 `UCE ≈ 6 V`，即给输出上下摆幅留出近似对称的余量。

## 3. 仪器、接线和安全

### 3.1 仪器

- 直流稳压电源：DP832A
- 信号发生器：Tek AFG1062 或 DG4062
- 示波器：Tek MSO2012B
- 两台万用表：Fluke F287C、Fluke 17B+
- 9 孔插件方板、短接桥和导线

### 3.2 接线原则

1. 所有接线、换元件、换负载都在**断开直流电源和信号源**后进行。
2. 直流电源负端、信号发生器地、示波器各通道地、实验电路地必须共地。
3. 示波器只观察交流分量时使用 `AC` 耦合；测集电极直流电位 `VC` 时使用 `DC` 耦合。
4. 信号发生器输出必须先用万用表交流 mV 档调到要求值，再接入电路。
5. 用万用表测三极管二极管特性时，优先用香蕉头导线接触，不使用表笔尖，以减小接触电阻。
6. 出现波形异常、异常声音或元件发热，立即断电检查。

### 3.3 上电前清单

- [ ] 三极管型号和极性确认，已用二极管档检查正常。
- [ ] `Rc=2.4 kΩ`、`Re=1 kΩ`、`Rb1=Rb2=20 kΩ`、`Rp=100 kΩ` 初始电路核对无误。
- [ ] `C1`、`C2`、`Ce` 极性和位置正确。
- [ ] 电源设为 `+12 V`，信号源设为正弦、`1 kHz`、`10 mV RMS`。
- [ ] 示波器 CH1 接输入端，CH2 接输出端，地线接公共地。
- [ ] 没有任何带电换线或带电插拔元件的计划。

## 5. 完整实验流程

### 步骤 A：检查三极管并搭建初始电路

1. 断开所有电源。
2. 用万用表二极管档检查 9013 的 `B-E`、`B-C` PN 结是否正常，并确认管脚排列。不同器件封装管脚顺序可能不同，不能只凭外形猜测。
3. 按图 5-3 搭建电路，初始使用 `Rb1=Rb2=20 kΩ`、`Rp=100 kΩ` 可调、`Rc=2.4 kΩ`、`Re=1 kΩ`、`Ce=47 μF`。
4. 先不接入电路，单独用万用表交流 mV 档把信号源调为正弦 `f=1 kHz`、`Ui=10 mV RMS`。

### 步骤 B：调节合适的静态工作点

1. 将输入信号和 `+12 V` 电源接好，检查无误后上电。
2. 示波器 CH1 接放大器输入端，CH2 接输出端；确认三台仪器和电路共地。
3. 等输出稳定后，示波器输入、输出通道均用 `AC` 耦合，确认输出正弦波被放大且没有明显削顶。
4. 关闭/停止信号源，保留直流电源，缓慢调节 `Rp`，使 `UCE` 接近理论最佳值 `6 V`。
5. 工作点稳定后，关闭信号源，使用万用表直流电压档测量：`UBE`、`UCE`、`VB`、`VE`、`VC`。
6. 断开电源并将待测电阻从电路中拔出或至少与电路隔离，测量 `Rc`、`Re`、`Rp`、`Rb1`、`Rb2` 实际阻值。
7. 把数据填入数据记录页表 5-2，并计算 `IB`、`IC` 和 `β`。

### 步骤 C：观察 `Ce` 对增益的影响

1. 静态工作点测完后接入 `RL=1 MΩ`，保持 `Rp` 不变。
2. `Ce=47 μF` 时，上电并保持 `Ui=10 mV RMS`、`f=1 kHz`；用交流档测量实际 `Ui` 和输出有效值 `Uo`。
3. 用示波器 `AC` 耦合同时观察并记录 `ui`、`uo`，注意两者反相。
4. 关闭信号源和直流电源后断开 `Ce`。**改变 `Ce` 时必须先断开两种电源。**
5. 再次上电，在相同 `Ui`、`f`、`RL` 和 `Rp` 条件下测 `Uo`、计算 `Au`、记录波形。
6. 将两组结果填入表 5-3，说明 `Ce` 接入与否对增益的影响。

### 步骤 D：测量负载对增益的影响

1. 恢复 `Ce=47 μF`，保持静态工作点和输入条件不变。
2. 依次设置：`RL=∞`（开路）、`RL=10 kΩ`、`RL=1 kΩ`。
3. 每次更换负载前先关闭电源；更换后再上电测量实际 `Ui`、`Uo`。
4. 计算各组 `Au`，填入表 5-4，并解释负载变化的原因。

### 步骤 E：观察静态工作点对失真的影响

本步骤接入 `RL=1 MΩ`。输入、输出波形测量用 `AC` 耦合；判断集电极直流峰值时，示波器需要切换为 `DC` 耦合。

#### E1. Q 点合适

1. 按步骤 B 将 `UCE` 调到约 `6 V`。
2. `Ui=10 mV RMS`、`f=1 kHz`，记录无失真输入/输出波形。
3. 逐渐增大 `Ui`（注意 `Ui<40 mV`），记录最大不失真输出有效值 `Uo,max`。
4. 继续增大输入，观察输出同时出现饱和和截止削顶的状态并画波形。

#### E2. Q 点接近饱和区（`Rp` 减小）

1. 先保持输入不变，逐渐减小 `Rp`，提高静态工作点，使集电极电位 `VC` 约在 `5 V` 以内。
2. 观察并记录输出下部出现明显平坦区的饱和失真波形。
3. 逐渐减小 `Ui`，记录该工作点的最大不失真 `Uo,max`。
4. 关闭信号源，用直流电压档测 `UBE`、`UCE`、`VB`、`VC`；结合步骤 B 测得的电阻实际值计算 `IB`、`IC`，填入表 5-5。

#### E3. Q 点接近截止区（`Rp` 增大）

1. **先断开直流电源**，再将 `Rb1` 换为 `100 kΩ`，将 `Rp` 换为 `220 kΩ` 可调电阻。
2. 调大 `Rp`，降低静态工作点，使 `VC` 约为 `11 V`。
3. 将输入改为 `Ui=20 mV RMS`、`f=1 kHz`，观察并记录输出上部出现明显平坦区的截止失真波形。
4. 逐渐减小 `Ui`，记录最大不失真 `Uo,max`。
5. 关闭信号源，用直流电压档测 `UBE`、`UCE`、`VB`、`VC`；使用步骤 B 的 `Rc`、`Re` 实测值计算 `IB`、`IC`，填入表 5-5。

## 6. 数据处理公式

### 6.1 电压增益

对每一组交流测量数据，使用有效值计算：

```text
Au = Uo / Ui
```

若要保留相位信息，可写成带符号的电压增益；表格中的 `Au` 通常填写幅值，另在波形栏注明输出反相。

指导书给出的共射极电压增益关系为：

```text
Au = Uo / Ui = -β · R'L / rbe
```

其中 `R'L` 是集电极侧的交流等效负载，常近似为 `Rc || RL`；`rbe` 是三极管基极-发射极小信号输入电阻。实际电路还会受 `Re`、`Ce`、仪器内阻和三极管参数影响，因此以实测值为准。

### 6.2 静态电流和电流放大系数

电阻统一换算为欧姆后再代入：

```text
IC ≈ (VCC - VC) / Rc
IE ≈ VE / Re
IB ≈ IE - IC
β  = IC / IB
```

这是利用发射极和集电极电流的关系进行的实测估算。也可以利用分压支路电流做校核：

```text
I_Rb1 = (VCC - VB) / (Rp + Rb1)
I_Rb2 = VB / Rb2
IB     ≈ I_Rb1 - I_Rb2
```

两种方法结果有差异时，优先检查：电阻是否脱离电路测量、`VC` 的参考地是否正确、`VCC` 是否确为 `12 V`、以及三极管是否接反。

### 6.3 读数和单位

- `Ui` 使用交流有效值，单位为 `mV`；代入 `Au` 前换算为 `V` 或保持同一单位。
- `Uo` 使用交流有效值，单位为 `V`。
- `UBE`、`UCE`、`VB`、`VE`、`VC` 使用直流电压档，单位为 `V`。
- `IB` 填 `μA`，`IC` 填 `mA`，`β` 无单位。
- `Uo,max` 指仍保持不失真的最大输出有效值，不是已经削顶后的输出。

## 7. 波形判据和物理解释

### 7.1 正常放大

输入、输出都是近似正弦；输出幅值更大，且相对输入反相约 `180°`。

### 7.2 饱和失真

对本实验 NPN 共射极电路，`Rp` 减小使 Q 点上移、`VC` 降低。输入使基极电流进一步增大时，三极管进入饱和，集电极电压不能继续按线性关系下降，因而**输出波形下部出现平坦/削顶**。

### 7.3 截止失真

`Rp` 增大使 Q 点下移、`VC` 接近 `VCC`。输入使基极电流减小时，三极管趋于截止，集电极电压接近 `VCC`，因而**输出波形上部出现平坦/削顶**。指导书给出的判据是用示波器 `DC` 耦合观察集电极电位峰值约 `11.5 V`。

### 7.4 为什么 PNP 不能直接套用“上部/下部”结论

上述上下削顶判据与 NPN 的电流、电压极性和共射极反相关系有关。换成 PNP 后，电源极性、载流方向和输出摆幅方向改变，不能机械地沿用本实验 NPN 的“上部为截止、下部为饱和”结论，应根据器件极性和集电极电位实际变化重新判断。

## 8. 现象解释要点

### 8.1 `Ce` 接入后通常增益变大

交流时，`Ce` 将发射极旁路到地，使 `Re` 对交流信号的负反馈减弱，发射极交流电压摆动变小，因而电压增益通常增大。`Ce` 断开时，`Re` 参与交流负反馈，增益下降，但线性和稳定性往往更好。

### 8.2 `RL` 变小后增益下降

集电极交流等效负载近似为 `R'L = Rc || RL`。`RL` 变小会使 `R'L` 变小，根据增益公式，`Uo` 和 `Au` 通常下降；同时负载还可能使波形更早达到失真。

### 8.3 提高电压增益的方向

在不引入明显失真、不过载且稳定的前提下，可以考虑：接入合适的 `Ce`、增大集电极交流负载（如增大 `Rc` 或减轻 `RL`）、选用 `β` 较大的三极管、减小交流发射极负反馈。实际改动要同时检查 Q 点和最大不失真输出范围。

## 9. 故障排查顺序

### 9.1 常见原因

- 接线错误、接触不良、断路或短路。
- 元件型号或阻值装错，电源输出端接错。
- 电源、信号源、示波器与电路没有共地。
- 电解电容极性接反。
- 电阻在电路中直接测量，读数被并联支路影响。
- 示波器仍在 `DC` 耦合而把直流偏置误认为交流波形，或反过来。

### 9.2 推荐检查顺序

1. 立即断电，目测三极管管脚、短接桥、电源正负端和电容极性。
2. 断电用电阻档检查应导通处是否开路、应隔离处是否短路。
3. 上电后用直流电压档逐点检查 `VCC`、`VC`、`VE`、`VB` 是否符合当前 Q 点预期。
4. 单独确认信号源的频率和有效值，再接入电路。
5. 确认示波器探头地线接公共地、通道量程合适、耦合方式正确。
6. 发现异常声音、发热或波形突然异常时不要继续调节，先断电。
