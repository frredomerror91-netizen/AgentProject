# 日常问题解决成果库 / Everyday Problem-Solving Outputs

这是一个用于沉淀 AI Agent 协助解决日常问题所产生的成果的项目。这里保存经过整理、核对或可直接复用的输出，例如说明文档、清单、计划、数据整理结果和其他交付物，便于后续查阅、复用与持续完善。

This project preserves useful outputs created with the help of AI agents for everyday problems. It stores reviewed, organized, or directly reusable deliverables, such as documentation, checklists, plans, processed data, and other artifacts for later reference, reuse, and improvement.

## 项目内容 / What's Included

- 与实际问题对应的最终交付物和参考材料
- 可复用的模板、操作清单和决策记录
- 为完成任务而准备的草稿、分析和临时工作文件
- 必要的背景说明、来源信息和使用限制

- Final deliverables and reference materials tied to real-world problems
- Reusable templates, checklists, and decision records
- Drafts, analysis, and temporary working files prepared during a task
- Necessary context, source information, and usage limitations

## 目录说明 / Directory Structure

| 目录 / Directory | 用途 / Purpose |
| --- | --- |
| `outputs/` | 面向使用者的最终成果。每项成果应尽量具备清晰名称、必要说明和可独立使用的内容。 / Final user-facing deliverables. Each item should have a clear name, necessary context, and standalone usability where practical. |
| `work/` | 任务过程中的草稿、分析、素材和临时文件。内容可随任务结束而整理或移除。 / Drafts, analysis, source materials, and temporary files used during work. Content may be organized or removed after a task is complete. |

## 使用说明 / How to Use

请优先从 `outputs/` 查找可直接使用的成果，并根据文件名、说明或所在主题目录定位相关内容。使用前请确认材料的适用范围、创建时间和数据来源；涉及重要决策、金额、法律、医疗或安全事项时，应结合可靠的原始资料和专业意见进行判断。

Start with `outputs/` for ready-to-use deliverables, then locate the relevant material by its name, description, or topic directory. Before using an item, confirm its intended scope, creation date, and data sources. For important decisions involving money, law, health, or safety, consult reliable primary sources and qualified professional advice as appropriate.

## 维护约定 / Maintenance Guidelines

- 将最终成果放入 `outputs/`，将过程性文件保留在 `work/`。
- 使用能够表达主题和用途的文件名，例如 `2026-09-17-旅行预算清单.md`。
- 为需要上下文的成果注明目标、关键假设、来源和更新日期。
- 更新既有成果时，优先保留其用途和历史背景，避免无说明地覆盖重要信息。
- 不提交密码、令牌、身份证件、账户信息、私密对话或其他敏感个人数据。

- Place final deliverables in `outputs/` and keep process files in `work/`.
- Use filenames that describe the topic and purpose, such as `2026-09-17-travel-budget-checklist.md`.
- For outputs that need context, record the objective, key assumptions, sources, and update date.
- When updating an existing artifact, preserve its purpose and relevant history; avoid replacing important information without explanation.
- Do not store passwords, tokens, identity documents, account details, private conversations, or other sensitive personal data.
