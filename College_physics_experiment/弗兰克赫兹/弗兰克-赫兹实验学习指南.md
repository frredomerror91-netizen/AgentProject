# 弗兰克-赫兹实验学习指南

本指南根据《弗兰克-赫兹实验指导书》和《实验10 弗兰克赫兹实验》报告模板整理，目的是帮助你从零完成实验、记录数据并填写报告。

## 一、实验要做什么

本实验用充氩弗兰克-赫兹管测量板极电流 IA 随第二栅极电压 UG2K 的变化，观察电流曲线的周期性峰谷，从而验证氩原子能级是分立的，并求出氩原子的第一激发电位。

指导书规定的任务有三项：

1. 手动测绘弗兰克-赫兹管的 IA-UG2K 曲线。
2. 自动测绘 IA-UG2K 曲线。
3. 测定氩原子的第一激发电位。

公认的氩原子第一激发电位为 U0 ≈ 11.7 V，实验结果应与此值比较，但不能把公认值当作自己的测量结果。

## 二、实验原理

### 1. 玻尔原子能级理论

玻尔理论的核心内容是：

- 原子只能处在若干个稳定的定态，每个定态有确定能量，能量取值是分立的。
- 原子在定态之间跃迁时才吸收或发射能量，能量差满足

  \[
  h\nu=E_m-E_n.
  \]

- 电子与原子碰撞时，若电子的动能恰好达到某一能级差，原子可以吸收这部分能量，从基态跃迁到激发态。对于氩原子的第一激发过程：

  \[
  eU_0=E_2-E_1.
  \]

因此，测出使电子发生非弹性碰撞的特征电压，就可以得到氩原子的第一激发电位。

### 2. 弗兰克-赫兹管如何测出能级差

热阴极 K 发射电子。电子在 K-G2 区域被 (U_{G2K}) 加速，并在 G2-A 区域受到反向拒斥电压 (U_{G2A}) 的筛选：只有穿过 G2 后剩余能量足以克服拒斥电场的电子，才能到达板极 A，形成板极电流 (I_A)。

当电子能量还不足以激发氩原子时，增大 (U_{G2K}) 会使到达 A 的电子数增加，(I_A) 总体上升。当电子在 G2 附近与氩原子发生非弹性碰撞，把约 (E_2-E_1) 的能量交给氩原子后，电子剩余能量下降，不能越过拒斥区，(I_A) 就出现明显下降。

随着 (U_{G2K}) 继续增大，电子又可能在碰撞后获得足够能量到达 A，电流再次上升；当电子获得约两倍、三倍激发能量时，还会发生第二次、第三次激发碰撞，于是曲线出现近似周期性的峰谷。

理想情况下，电流下降位置满足

\[
U_{G2K}\approx nU_0\quad(n=1,2,3,\ldots),
\]

相邻峰或相邻谷对应电压之差的平均值就是氩原子的第一激发电位 (U_0)。

## 三、四种电压的作用

实验仪需要设置四种电压，名称均以阴极 K 为参考：

| 电压 | 作用 |
|---|---|
| 灯丝电压 | 加热阴极，使阴极达到热发射温度并发射电子。电压过高会加速灯管老化，不能超过测试架标注参考值 0.5 V。 |
| 第一栅压 (U_{G1K}) | 调节电子从阴极向第一栅极方向的初始运动状态和电子束条件，使电子发射、引出过程处于规定工作状态。应按测试架出厂参考值设置。 |
| 第二栅压 (U_{G2K}) | 电子的主要加速电压，是实验扫描量。逐渐改变它，使电子获得不同动能，记录相应板极电流 (I_A)，得到 (I_A-U_{G2K}) 曲线。 |
| 拒斥电压 (U_{G2A}) | 在第二栅极和板极之间形成反向电场，筛选电子。只有剩余能量足够的电子能到达 A，因此非弹性碰撞会在板极电流中表现为明显下降。 |

## 四、实验前准备与接线

1. 按测试架标识，将测试仪四路输出分别接到弗兰克-赫兹管测试架：
   - (U_{G2K}) 输出接第二栅压接口；
   - (U_{G2A}) 输出接拒斥电压接口；
   - (U_{G1K}) 输出接第一栅压接口；
   - 灯丝电压输出接灯丝接口。
2. 将测试架的微电流输出接到测试仪的微电流输入接口。
3. 将测试仪“信号输出”接示波器 CH1，将“同步输出”接示波器触发端。
4. 开机。默认工作方式为“手动”。
5. 依次选中灯丝电压、(U_{G1K})、(U_{G2A})、(U_{G2K})，分别调到测试架或仪器标示的出厂参考值。
6. 灯丝电压不要超过参考值 0.5 V；仪器连续工作时间不要超过 2 小时。
7. 选中 (U_{G2K})，把其输出调为 0 V。
8. 预热 10--15 分钟，确认各电压稳定后再开始测量。

注意：接线错误可能损坏弗兰克-赫兹管；正式接线或改线前应关闭电源并核对接口名称。

## 五、手动测量流程

手动数据是报告的主要原始数据来源。

### 1. 设置扫描步长

在手动模式下，实验前可通过组合键把 (U_{G2K}) 的最小步进设为 0.1 V、0.2 V 或 0.5 V。通常优先选较小步长以提高峰谷定位精度；一旦开始记录，不能中途改变步长。

### 2. 扫描并记录数据

1. 选中 (U_{G2K})。
2. 从 0 V 开始，将 (U_{G2K}) 单向逐步增大到 90 V。
3. 每一个电压点记录：
   - (U_{G2K})；
   - 仪器显示的板极微电流 (I_A)。
4. 同时观察示波器波形，用于判断曲线整体形状和峰谷位置。
5. 扫描过程中不要把电压反复调回，也不要改变步长。

建议原始记录表至少包含：

| 序号 | (U_{G2K})/V | (I_A)/（仪器单位） | 备注 |
|---:|---:|---:|---|
| 1 |  |  |  |
| 2 |  |  |  |

“备注”可记录明显峰值、波谷、读数跳动或操作异常。

### 3. 改变拒斥电压后重复

将 (U_{G2A}) 增加或减小 0.5 V，然后重复从 0 V 到 90 V 的 (U_{G2K}) 扫描，得到第二条 (I_A-U_{G2K}) 曲线。比较两条曲线的峰谷位置、幅度和清晰程度。

## 六、自动测量流程

1. 按下“自动/手动”按钮，选择“自动”模式，确认指示灯亮。
2. 选中 (U_{G2K}) 设置。
3. 按下“启/停”按钮开始自动测量，确认启停指示灯亮。
4. 仪器按默认 0.2 V 步进自动增加 (U_{G2K})，同步采集微电流并输出波形。
5. 调整示波器的垂直幅度、扫描时间和触发，使波形稳定显示。

指导书将自动测量主要用于实时观察现象；报告中的定量数据处理以手动测量数据为主，除非教师另有要求。

## 七、数据处理与报告填写

### 1. 绘制曲线

用计算机软件（如 Excel、Origin、Python 等）绘制散点图或折线图：

- 横坐标：(U_{G2K})/V；
- 纵坐标：(I_A)；
- 两组 (U_{G2A}) 条件应标明图例；
- 不要把不同拒斥电压的数据混成一组。

报告模板的“数据处理”要求明确写出：绘制 (I_A-U_{G2K}) 曲线，并对曲线进行拟合。

### 2. 读取峰值或波谷电压

从曲线中读出连续峰值电压 (U_1,U_2,\ldots,U_N)，或连续波谷电压。读数应使用同一种特征（全用峰或全用谷），不要在同一次计算中混用峰和谷。

### 3. 逐差法

若有 (N) 个同类特征电压，可用相隔 (m) 个周期的逐差：

\[
\Delta U_i=U_{i+m}-U_i,\qquad i=1,2,\ldots,N-m.
\]

每个逐差对应 (m) 个激发电位，因此

\[
U_{0,i}=\frac{\Delta U_i}{m},
\qquad
\bar U_0=\frac{1}{N-m}\sum_i U_{0,i}.
\]

也可直接取相邻差值的平均。使用较大间隔 (m) 往往能减小单次读数误差，但可用的差值数量会减少。报告中应列出特征电压、逐差值、各次 (U_{0,i}) 和平均值。

### 4. 最小二乘法

把第 (n) 个峰（或谷）的电压记为 (U_n)，建立线性模型

\[
U_n=a+nU_0.
\]

对 (U_n) 与序号 (n) 作线性拟合，拟合直线斜率就是第一激发电位 (U_0)。截距 (a) 吸收了接触电势、初始能量等造成的整体偏移。报告中应给出拟合方程、斜率和必要的拟合图。

### 5. 相对误差

与指导书给出的公认值 U0_ref = 11.7 V 比较：

\[
\text{相对误差}=\frac{|U_0-U_{0,\mathrm{ref}}|}{U_{0,\mathrm{ref}}}\times100\%.
\]

逐差法和最小二乘法应分别给出结果和相对误差。

### 6. 可选的能级差与波长换算

若要进一步表示能级差：

\[
E_2-E_1=eU_0.
\]

原子退激发时发出的光子满足

\[
\lambda=\frac{hc}{eU_0}.
\]

取 U0 = 11.7 V 时，指导书给出的数量级约为 1.05×10^-7 m。这不是本实验报告的核心必填结果，除非教师要求计算。

## 八、现象分析要点

- 曲线先上升：加速电压增加，到达板极的电子数增加。
- 出现波谷：电子发生非弹性碰撞并激发氩原子，碰撞后电子能量不足以克服拒斥电压。
- 波谷近似周期出现：电子可能经历一次、两次、三次等激发碰撞。
- 波谷电流随电压增大而逐渐增大：更高能量的电子即使经历激发碰撞，碰撞后仍可能有较大剩余能量；同时电子束和空间电荷等实际因素使基线电流整体抬升，因此后续波谷通常不会降到同一电流水平。
- 两条不同 (U_{G2A}) 曲线的差异：拒斥电压改变了电子筛选条件，峰谷的电流幅度和清晰程度会变化；特征间距仍应主要反映氩原子的激发电位。

## 九、常见错误与检查清单

- 接线前未按接口名称核对，尤其混淆 (U_{G1K})、(U_{G2K}) 和 (U_{G2A})。
- 灯丝电压超过参考值，或仪器连续工作超过 2 小时。
- 未预热 10--15 分钟就开始记录，导致电流漂移。
- 手动扫描中改变步长、反向调节或漏记数据。
- 两个 (U_{G2A}) 条件的数据未分组保存。
- 用峰值和波谷混合计算，或把自动示波器波形直接当作手动原始数据。
- 只报告 (U_0)，没有给出曲线、拟合、逐差过程和相对误差。

## 十、报告结构对照

根据报告模板，完成后应至少包含：

1. 实验预习：玻尔原子能级理论、四种电压的作用。
2. 实验现象及原始数据记录：手动扫描数据和必要的现象描述。
3. 数据处理：两组曲线、曲线拟合、逐差法、最小二乘法、相对误差。
4. 实验结论及现象分析：是否观察到周期性峰谷、测得的第一激发电位及与公认值的比较、自动与手动测量对比。
5. 讨论题：指导书末尾的三个问题。

自动测量部分可以写成：自动模式按 0.2 V 步进连续采集并实时显示曲线，操作方便、波形连续；手动模式便于逐点读取和记录原始数据，定量处理以手动数据为主。具体优缺点应结合你实际看到的曲线描述。
