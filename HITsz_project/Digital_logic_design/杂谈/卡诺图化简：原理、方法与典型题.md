# 卡诺图化简：原理、方法与典型题

> 卡诺图（Karnaugh Map，简称 K-map）把布尔函数的真值表重新排列成“相邻格只差一个变量”的图表。通过圈选相邻的 `1` 或 `0`，可以直观地消去变化变量，得到项数更少、门级更浅的逻辑表达式。

本文采用数字逻辑中常用的记号：`+` 表示 OR，相邻表示 AND，`A'` 表示 NOT A。

## 1. 卡诺图的原理

### 1.1 从代数合并到图形合并

布尔代数中的合并规则是：

```text
XY + XY' = X(Y+Y') = X
```

右边的 `Y` 和 `Y'` 互补，合并后被消去。卡诺图把两个只差一个变量的最小项放在相邻格中，因此相邻的 `1` 可以圈成一组；组内变化的变量消失，保持不变的变量留下。

例如，`m5=AB'C` 和 `m7=ABC` 只在 `B` 上不同，合并为 `AC`。四个相邻最小项可以消去两个变量，八个相邻最小项可以消去三个变量。

### 1.2 为什么必须使用格雷码

卡诺图的行列标签不是普通二进制顺序，而是格雷码顺序：相邻标签只改变一位。三变量图常用 `BC=00,01,11,10`，四变量图常用 `CD=00,01,11,10`。图的最左列和最右列也相邻，最上行和最下行也相邻，因此卡诺图在拓扑上类似“首尾相接”的表面。

### 1.3 卡诺图能优化什么

卡诺图主要用于寻找两类简化：

- **最简与或式（SOP）**：圈 `1`，每组得到一个乘积项，所有项相或。
- **最简或与式（POS）**：圈 `0`，每组得到一个和项，所有项相与。

“最简”通常指项数少、每项文字数少；实际电路设计还要考虑门数量、逻辑层数、扇入、冒险和共享项，所以代数项数最少不一定是唯一的工程最优方案。

## 2. 卡诺图的基本用法

### 2.1 二变量卡诺图

二变量函数只需 4 个格：

| A\\B | 0 | 1 |
|---|---:|---:|
| 0 | m0 | m1 |
| 1 | m2 | m3 |

圈两个相邻 `1` 可消去一个变量，圈四个 `1` 得到常量 `1`。例如 `F=Σm(1,3)` 形成整列 `B=1`，所以 `F=B`。

### 2.2 三变量卡诺图

规定行使用 `A`，列使用 `BC`：

| A\\BC | 00 | 01 | 11 | 10 |
|---|---:|---:|---:|---:|
| 0 | m0 | m1 | m3 | m2 |
| 1 | m4 | m5 | m7 | m6 |

注意列顺序是 `00,01,11,10`，不是 `00,01,10,11`。

**圈组的文字读取方法：**

1. 找出组中不变的行变量和列变量。
2. 某变量恒为 `1`，写原变量；恒为 `0`，写补变量；发生变化则不写。
3. 每组大小必须是 `1,2,4,8...`，不能是 3、6 等非二的幂。

例如三变量图中一组位于 `A=1` 的整行，得到 `A`；一组覆盖 `BC=01` 与 `BC=11` 两列，得到 `C`（因为 `B` 变化而 `C=1` 不变）。

### 2.3 四变量卡诺图

行用 `AB=00,01,11,10`，列用 `CD=00,01,11,10`：

| AB\\CD | 00 | 01 | 11 | 10 |
|---|---:|---:|---:|---:|
| 00 | m0 | m1 | m3 | m2 |
| 01 | m4 | m5 | m7 | m6 |
| 11 | m12 | m13 | m15 | m14 |
| 10 | m8 | m9 | m11 | m10 |

可能的合法组包括：单格、相邻两格、四格矩形、八格矩形、全图十六格。矩形可以跨边界，例如最左列和最右列组成一组，最上行和最下行也可组成一组。

### 2.4 五变量卡诺图

五变量通常画成两张四变量图：一张对应 `E=0`，一张对应 `E=1`。两张图中相同位置的格互相相邻，可以跨图合并。五变量卡诺图适合少量项的手工化简；变量更多时宜使用 Quine-McCluskey 法或逻辑综合工具。

## 3. 圈组规则与关键知识点

### 3.1 必须遵守的六条规则

1. 只圈目标值：SOP 圈 `1`，POS 圈 `0`。
2. 组的大小必须是 `2^k`。
3. 每组必须是图上的矩形，不能斜着连，也不能出现“L”形或缺角矩形。
4. 组内每个格必须是目标值；允许组之间重叠。
5. 允许跨左右、上下边界圈组。
6. 每个目标格至少被一个组覆盖；圈组应尽量大、尽量少。

### 3.2 质蕴含项与必选组

- **蕴含项**：由某个合法圈组得到的乘积项（圈 `1` 时）或和项（圈 `0` 时）。
- **质蕴含项**：不能再扩大的最大圈组。
- **本质质蕴含项**：至少覆盖一个没有被其他质蕴含项覆盖的目标格，必须选择。

实战时先找本质质蕴含项，再覆盖剩余目标格。如果一个格可由多个组覆盖，最后要比较“增加一个组”和“扩大已有组”的代价。

### 3.3 重叠圈与冗余圈

重叠是允许且经常必要的。例如一个四格组能覆盖两个孤立区域的公共格，两个更大的组重叠后可以让表达式少一项。反过来，如果某个圈中的所有格已经被其他圈覆盖，且删除它不会增加项数，则它通常是冗余圈。

### 3.4 不关心项（don't care）

不关心项记作 `X` 或 `d`。圈 `1` 时可以把 `X` 当作 `1` 来扩大组，也可以忽略；圈 `0` 时可把它当作 `0`。选择目标是让必需项更大、更少，但不能用 `X` 覆盖本来必须为另一个值的格。

### 3.5 相邻与“只差一位”

在卡诺图中相邻不仅是视觉上的上下左右相邻，还包括首尾相接的边界相邻。两个格若对应的二进制变量组合只差一位，就能合并；差两位或更多位不能直接合并。

## 4. SOP 化简的标准流程

给定 `F=Σm(...)` 或真值表时，可按下列步骤操作：

1. 选定变量分配和格雷码标签。
2. 将所有最小项填入图中，`1` 填 1，其余填 0；若有 `d`，填 X。
3. 圈出尽可能大的本质质蕴含项。
4. 补充圈组，覆盖所有 `1`，必要时利用 X。
5. 读取各组的不变变量并相乘，再把各组相或。
6. 用真值表、代入关键项或代数展开验证。

**快速判断：** 圈 `2^k` 个格，得到的项含 `n-k` 个文字（`n` 是变量总数）。因此优先找 8 格组，再找 4 格、2 格和单格组。

---

## 5. POS 化简的标准流程

POS 的思路与 SOP 对偶：

1. 在图中填出 `0`，圈尽可能大的 `0` 组。
2. 对于一个 `0` 组，组内恒为 `0` 的变量写原变量，恒为 `1` 的变量写补变量，变化变量省略，并把这些文字相或。
3. 各组和项相与。

例如四变量图中一组覆盖 `A=0,B=1` 的四个格，得到和项 `(A+B')`：当 `A=0` 时 `A` 为 0，当 `B=1` 时 `B'` 为 0，因此整个和项在该组为 0。

SOP 和 POS 可以分别化简，再比较电路实现代价；不要假设某一种形式总是更短。

## 6. 典型题目与解析

### 题目一：三变量的边界相邻

求最简 SOP：

```text
F(A,B,C)=Σm(0,2,4,6)
```

**解析：** 四个最小项在三变量图中对应 `C=0` 的两列（`BC=00` 和 `10`），这两列虽然位于左右边界，却是相邻的。组内 `A`、`B` 都变化，只有 `C=0` 不变，因此：

```text
F=C'
```

若错误地把列顺序按 `00,01,10,11` 排列，可能看不到这组边界合并，这是卡诺图最常见的入门错误之一。

---

### 题目二：本质质蕴含项与重叠

求最简 SOP：

```text
F(A,B,C,D)=Σm(0,1,2,3,5,7,8,9,10,11,13,15)
```

**解析：** 使用四变量图：

- `m0,m1,m2,m3,m8,m9,m10,m11` 可组成八格组。这里 `B=0` 不变，得到 `B'`。
- `m1,m3,m5,m7,m9,m11,m13,m15` 可组成八格组。这里 `D=1` 不变，得到 `D`。

两组覆盖全部给定最小项，且各自都是最大组。因此：

```text
F=B'+D
```

两组有重叠并不是问题；重叠反而使表达式只需两个项。若只圈四格小组，会得到更多文字，虽然逻辑上仍正确，但不是最简结果。

---

### 题目三：含孤立项的最简化

求最简 SOP：

```text
F(A,B,C,D)=Σm(1,3,7,11,15)
```

**解析：**

1. `m3,m7,m11,m15` 可以组成四格组。它们的二进制末两位均为 `11`，且 `A`、`B` 变化，因此得到 `CD`。
2. `m1,m3` 可组成两格组，二进制为 `0001,0011`，不变变量为 `A'=1,B'=1,D=1`，得到 `A'B'D`。

所以：

```text
F=CD+A'B'D
```

`m1` 只能通过第二组覆盖，故第二组是必需的；不能为了追求“大组”而漏掉孤立的 `m1`。

---

### 题目四：利用不关心项扩大圈组

求最简 SOP：

```text
F(A,B,C,D)=Σm(1,3,9,11)+d(0,2,8,10)
```

**解析：** 必须覆盖的 `1` 是 `1,3,9,11`，而 `0,2,8,10` 是 X。八个格合在一起时，`B=0` 不变，`A,C,D` 都变化，得到：

```text
F=B'
```

如果忽略 X，只能把四个 `1` 圈成两组，得到 `B'D+A'B'D` 或其他较长表达式；使用 X 能把电路进一步简化。注意：X 不是必须输出 1，只是允许在化简时灵活使用。

---

### 题目五：由 0 化简 POS

求最简 POS：

```text
F(A,B,C,D)=ΠM(0,1,4,5,8,9,12,13)
```

**解析：** 这些最大项对应 `D=0` 的整张两列，共八个 `0`。圈这八个 `0` 时，只有 `D=0` 不变。对于 POS，恒为 0 的变量直接写原变量，因此：

```text
F=D
```

验证：当 `D=0` 时 `F=0`，当 `D=1` 时没有列出的最大项约束，函数为 1。这个例子说明圈 0 时不要机械套用 SOP 的“恒 0 写补变量”规则。

---

### 题目六：多解与代价比较

求最简 SOP，并指出是否存在不同但等价的最简结果：

```text
F(A,B,C,D)=Σm(2,3,6,7,8,9,10,11,14,15)
```

**解析：**

- `m2,m3,m6,m7,m10,m11,m14,m15` 可组成八格组。它们都满足 `C=1`，得到 `C`。
- `m8,m9,m10,m11` 可组成四格组，满足 `A=1,B=0`，得到 `AB'`。

因此：

```text
F=C+AB'
```

其中 `m8,m9` 只能由第二组覆盖，第二组是必需的；第一组覆盖其余项。若选择较小的其他圈组，可能得到三个或更多项，但不会优于上述两项结果。若某些圈组都能以相同项数、相同文字数覆盖全部 `1`，则最简式不一定唯一，应结合门数量和共享信号决定实现方案。

---

### 题目七：五变量跨图合并

设五变量函数的 `E=0` 图和 `E=1` 图中，位置 `ABCD=0101`、`0101` 均为 `1`，并且这两个位置在各自图中都能与相邻格组成相同的四格区域。说明跨图合并后能消去哪个变量。

**解析：** 两张图的对应格只在 `E` 上不同：一张是 `E=0`，另一张是 `E=1`。把对应格跨图合并，相当于使用：

```text
XE' + XE = X(E'+E)=X
```

因此变量 `E` 被消去。若两张图对应位置都为 `1`，必须检查是否能把两个同形区域合成更大的 `2^k` 组；跨图合并经常能比单独处理每张图少一个文字。

---

### 题目八：检查一个看似合法的圈组

某四变量卡诺图中，四个 `1` 位于 `m0,m1,m4,m5`。另有一个 `1` 位于 `m7`。有人将 `m0,m1,m4,m5,m7` 五格一起圈成一组。判断是否正确，并给出正确处理。

**解析：** 五不是二的幂，不能作为一个合法圈组。前四格形成 2×2 的四格组，二进制上 `A=0,B=0` 或 `A=1,B=0`，所以只有 `B=0` 不变，得到 `B'`。`m7` 必须另找包含它的合法组；如果没有相邻的其他 `1` 或 X，只能单独圈 `m7`，得到对应三文字项 `AB C D`（按该格实际编码确定原变量或补变量）。

这类题的关键不是“尽量把看起来靠近的格都圈进去”，而是“每个组必须是大小为二的幂的矩形”。

## 7. 常见错误与检查清单

### 7.1 常见错误

- 把标签写成普通二进制顺序，导致错误判断相邻关系。
- 忘记边界相邻，错过更大的组。
- 圈出 3 格、5 格或缺角矩形。
- 圈组过小，或为了少圈一次而漏掉某个 `1`。
- 圈 `1` 时把 0 包进组，或圈 `0` 时把 1 包进组。
- 读取项时把“变化的变量”写进结果。
- 把 X 当成必须为 1，从而改变了原函数对有效输入的要求。
- 得到一个表达式后没有回代验证，尤其是存在多个合法最简式时。

### 7.2 交卷前检查清单

1. 变量标签是否按格雷码排列？
2. 每个圈的大小是否为 `1,2,4,8...`？
3. 是否利用了合法的边界相邻和跨图相邻？
4. 所有必需的 `1`（或 `0`）是否都被覆盖？
5. 每组中保留下来的变量是否真的不变？
6. 是否能再扩大某个组，或删除某个冗余组？
7. 用一个未覆盖的最小项和一个关键最大项验证结果。

## 8. 进一步练习

1. 求 `F=Σm(0,1,2,3,8,9,10,11)` 的最简 SOP。
2. 求 `F=Σm(4,5,6,7,12,13,14,15)` 的最简 SOP，并说明它与第 1 题的对称性。
3. 求 `F=Σm(0,2,5,7,8,10,13,15)` 的最简 SOP。提示：至少有两个四格组。
4. 求 `F=ΠM(1,3,5,7,9,11,13,15)` 的最简 POS。
5. 求 `F=Σm(1,3,7,9,11,15)+d(0,2,8,10)`，比较使用和不使用 X 时的结果。

**练习参考结果：**

1. `B'`。
2. `B`。
3. `B'D'+BD`。两组分别对应 `B=0,D=0` 与 `B=1,D=1`，不能进一步合并。
4. `D'`。
5. 使用 X 时可得 `F=B'+CD`；不使用 X 时可得 `F=B'D+CD`。前者利用 X 将第一组扩大为 `B'`，文字数和逻辑层数都更少。

## 9. 总结

卡诺图的核心只有一句话：**把只差一个变量的项放在相邻位置，并尽可能把目标格组成最大的二的幂矩形。** 掌握格雷码、边界相邻、质蕴含项、重叠、无关项以及 SOP/POS 的变量读取规则，就能处理绝大多数三变量和四变量化简题。遇到五变量以上或约束复杂的函数，应把卡诺图作为理解和验证工具，再结合表格法或逻辑综合工具完成规模化优化。
