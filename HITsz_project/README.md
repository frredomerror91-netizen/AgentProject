# HITsz 课程学习资料与笔记 / HITsz Course Study Materials and Notes

这是一个结合 AI Agent 与HITsz学校课程资源整理的学习资料和笔记项目，旨在将课程中的重点内容沉淀为便于查阅、复习和理解的学习记录。

This project collects study materials and notes organized with AI agents and school course resources. It turns key course content into learning records that are easier to review, revisit, and understand.

## 项目内容 / What's Included

- 按课程或主题整理的知识总结
- 课程学习过程中的笔记与补充说明
- 可用于复习、查缺补漏和理解概念的参考资料
- Knowledge summaries organized by course or topic
- Notes and supplementary explanations from the learning process
- Reference materials for review, filling knowledge gaps, and understanding concepts

## 使用说明 / How to Use

你可以将本仓库作为学习时的参考资料：按课程目录查找相关主题，结合原始课件、教材和课堂内容进行学习与复习。

You may use this repository as a study reference: locate a topic in the relevant course directory, then study and review it alongside the original slides, textbooks, and class materials.

这些内容适合用于辅助学习，但不应替代课程教学、原始资料或独立思考。部分内容由 AI Agent 协助整理，建议在使用关键结论、公式或定义前对照课程资料进行核实。

These materials are intended to support learning, not replace instruction, source materials, or independent thinking. Some content was organized with assistance from AI agents; please verify important conclusions, formulas, and definitions against the course resources before relying on them.

## 说明 / Note

本仓库仅供学习和交流参考。课程相关资料的版权归原作者、授课教师或学校所有；请遵守所在课程和学校的相关规定，合理使用其中内容。

This repository is provided for study and discussion only. Copyright for course-related materials belongs to their original authors, instructors, or schools. Please follow the rules of your course and institution and use the content responsibly.
