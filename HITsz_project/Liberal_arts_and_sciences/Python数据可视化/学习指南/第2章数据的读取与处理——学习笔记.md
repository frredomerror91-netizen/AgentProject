## 2. 数据读取与写出

### 2.1 pandas 的读写体系

不同数据源最终都应读成 `DataFrame`，后续概览、清洗、合并和绘图都围绕这个对象进行。

| 数据源 | 读取                | 写出              | 关键注意事项                   |
| ------ | ------------------- | ----------------- | ------------------------------ |
| CSV    | `pd.read_csv()`   | `df.to_csv()`   | 编码、分隔符、是否写索引       |
| Excel  | `pd.read_excel()` | `df.to_excel()` | 工作表、`openpyxl`、多表写出 |
| 数据库 | `pd.read_sql()`   | `df.to_sql()`   | SQLAlchemy 连接、`if_exists` |

读取完成后的第一步不是分析，而是确认数据是否完整、类型是否正确、是否存在缺失值。

### 2.2 CSV

```python
import pandas as pd

df = pd.read_csv(
    "data/sales_2026.csv",
    sep=",",
    encoding="utf-8-sig",
    usecols=["order_time", "store", "product_id", "category", "amount"],
)
```

常用参数：

| 参数                   | 作用                                    |
| ---------------------- | --------------------------------------- |
| `filepath_or_buffer` | 文件路径或 URL                          |
| `sep`                | 字段分隔符，默认是`,`                 |
| `header` / `names` | 指定或自定义列名                        |
| `usecols`            | 只读取需要的列                          |
| `dtype`              | 预先指定数据类型                        |
| `encoding`           | 中文文件常试`utf-8-sig`，再试 `gbk` |
| `nrows`              | 只读取前$n$ 行，适合试读              |
| `chunksize`          | 分块读取大文件                          |

写出 CSV 时，教学和实际项目中通常使用：

```python
df.to_csv("output/clean_sales.csv", index=False, encoding="utf-8-sig")
```

`index=False` 避免把 pandas 行号写成多余的一列；`utf-8-sig` 便于 Excel 双击打开中文文件。

### 2.3 Excel

```python
sales = pd.read_excel("data/sales.xlsx", sheet_name="明细")
all_sheets = pd.read_excel("data/sales.xlsx", sheet_name=None)
```

`sheet_name=0` 表示第一张表，传入名称可以指定工作表，传入 `None` 会返回 `{表名: DataFrame}` 字典。读取 `.xlsx` 通常需要安装 `openpyxl`。

写一张表可以直接调用：

```python
sales.to_excel("output/sales.xlsx", index=False, sheet_name="明细")
```

写多张表必须使用 `ExcelWriter`，否则后写的表可能覆盖前面的内容：

```python
with pd.ExcelWriter("output/report.xlsx") as writer:
    sales.to_excel(writer, sheet_name="销售明细", index=False)
    summary.to_excel(writer, sheet_name="汇总", index=False)
```

Excel 单个工作表约有 $104$ 万行上限；数据量较大时应考虑 CSV 或数据库。

### 2.4 数据库

SQLAlchemy 连接字符串的一般形式为：

$$
\text{数据库产品}+\text{驱动}://\text{用户名}:\text{密码}@\text{主机}:\text{端口}/\text{数据库名}
$$

示例：

```python
from sqlalchemy import create_engine

conn_str = "mysql+pymysql://root:123456@localhost:3306/shop?charset=utf8"
engine = create_engine(conn_str)
orders = pd.read_sql(
    "SELECT order_time, store, category, amount FROM orders",
    con=engine,
    parse_dates=["order_time"],
)
```

`read_sql_table()` 读取整张表，`read_sql_query()` 只执行查询，`read_sql()` 两者都支持，最常用。大表可以设置 `chunksize` 分块返回。

写入数据库时要特别注意 `if_exists`：

| 值          | 行为                             |
| ----------- | -------------------------------- |
| `fail`    | 表存在则报错，默认值             |
| `replace` | 删除旧表后重建，可能造成数据丢失 |
| `append`  | 保留旧数据并追加新数据           |

## 3. 数据概览与描述性统计

### 3.1 四步概览法

```python
print(df.shape)       # 行数、列数
print(df.columns)     # 列名
df.info()             # 类型和非空计数
print(df.dtypes)      # 每列 dtype
print(df.head())      # 前几行
```

推荐顺序：

1. `shape`：判断数据是否读全；
2. `info()` / `dtypes`：确认类型是否符合预期；
3. `describe()`：观察量级、分布和潜在离群值；
4. `value_counts()`：检查分类值是否有拼写不一致。

### 3.2 `describe()` 与统计量

```python
df.describe()                         # 默认统计数值列
df.describe(include="object")        # 查看字符串/类别列
df["category"].value_counts(dropna=False)
```

| 统计量            | 解释与检查思路                     |
| ----------------- | ---------------------------------- |
| `count`         | 非空个数；与总行数的差额就是缺失数 |
| `mean`、`50%` | 差距很大时，可能存在偏斜或异常值   |
| `std`           | 离散程度，越大表示波动越大         |
| `25%`、`75%`  | 判断分布形态，也是 IQR 检测的基础  |
| `min`、`max`  | 异常值筛查入口，但必须结合业务判断 |

若某列 `max` 远大于 `75%` 分位数，应优先检查单位、录入和业务场景，而不是直接删除。

### 3.3 类型转换

```python
df["order_time"] = pd.to_datetime(df["order_time"], errors="coerce")
df["year"] = df["order_time"].dt.year
df["month"] = df["order_time"].dt.month

# 先去掉千分位和货币符号，再转数值
df["amount"] = (
    df["amount"].astype("string").str.replace(",", "", regex=False)
    .str.replace("￥", "", regex=False)
    .astype("float64")
)
```

含有 `NaN` 的 `float64` 不能直接转成 `int64`，应先处理缺失值。重复度高的字符串列可以转为 `category` 以节省内存；类别型数据若要参与数值计算，应先转换或映射为数值。

## 4. 数据清洗

总体流程是：**先检测，后定位，再处理，最后复核**。清洗没有脱离业务的唯一答案，每一次处理都应能解释和复现。

### 4.1 缺失值

```python
missing = df.isna().sum().to_frame("missing_count")
missing["missing_rate"] = missing["missing_count"] / len(df)
```

`isnull()` / `notnull()` 用于定位，`count()` 用于统计非空数量。先计算缺失占比，再决定策略：

| 方法              | 适用情况                                 | 风险                             |
| ----------------- | ---------------------------------------- | -------------------------------- |
| `dropna()`      | 缺失比例低、近似完全随机、该列非关键变量 | 样本量减少；非随机缺失会引入偏差 |
| `fillna()`      | 需要保留记录，且有合理代表值             | 会改变均值、标准差等统计量       |
| `interpolate()` | 有序数据或时间序列，缺口确实可由趋势估计 | 趋势假设错误会制造虚假数据       |

```python
# 删除：只在 amount 缺失时删除
clean = df.dropna(subset=["amount"])

# 按列指定填充值
df = df.fillna({"amount": df["amount"].median(), "store": "未知"})

# 时间序列插值
df = df.sort_values("order_time")
df["amount"] = df["amount"].interpolate(method="linear")
```

`dropna()` 的 `axis`、`how`、`thresh`、`subset` 控制删除范围；`fillna()` 支持标量、字典以及 `ffill` / `bfill`；时间序列按真实时间间隔插值时可使用 `method="time"`。

### 4.2 重复值

```python
print(df.duplicated().sum())
df = df.drop_duplicates(subset=["order_id"], keep="last")
df = df.reset_index(drop=True)
```

完全相同的记录可用 `drop_duplicates()`；同一业务对象但字段名不同或数值高度相似，则应结合 `corr()` 检查特征冗余。所谓“伪重复”要先按业务规则排序，再决定保留 `first` 还是 `last`。

### 4.3 异常值

**3σ 原则**适用于近似正态分布的连续变量。若均值为 $\mu$、标准差为 $\sigma$，通常把

$$
(-\infty,\mu-3\sigma)\cup(\mu+3\sigma,+\infty)
$$

之外的值视为高度异常，理论比例约为 $0.27\%$。

**IQR 准则**不要求正态分布，更稳健：

$$
IQR=Q_3-Q_1,\qquad
L=Q_1-1.5IQR,\qquad
U=Q_3+1.5IQR
$$

低于 $L$ 或高于 $U$ 的值可标记为异常。处理前先判断成因：录入错误可修正或删除，采集故障可转为缺失，业务上真实存在的大额订单应保留。

```python
q1, q3 = df["amount"].quantile([0.25, 0.75])
iqr = q3 - q1
lower, upper = q1 - 1.5 * iqr, q3 + 1.5 * iqr

is_outlier = ~df["amount"].between(lower, upper)
df_without_outlier = df.loc[~is_outlier].copy()
df_capped = df.copy()
df_capped["amount"] = df_capped["amount"].clip(lower, upper)
```

异常值不等于错误值。如果拿不准，可以分别保留和剔除异常值，比较两版分析结论。

## 5. 数据合并与重塑

合并前先对齐时间范围、粒度、时间格式、时区和字段命名；合并后检查 `shape`、新增的 `NaN` 以及主键是否重复。

### 5.1 `concat()`：按轴堆叠

```python
# 结构相同的多个月份数据纵向追加
all_sales = pd.concat([sales_jan, sales_feb], axis=0, ignore_index=True)

# 按索引横向拼接，行索引对齐
wide = pd.concat([sales, weather], axis=1, join="inner")
```

`axis=0` 增加行，`axis=1` 增加列；`join="outer"` 取另一轴索引并集并补 `NaN`，`join="inner"` 只保留交集。`append()` 已在 pandas 3.x 移除，统一使用 `concat()`。

### 5.2 `merge()` 与 `join()`：按键关联

```python
result = sales.merge(
    products,
    on="product_id",
    how="left",
    validate="many_to_one",
    indicator=True,
    suffixes=("_sales", "_product"),
)
```

`how` 决定保留哪些行：`inner` 只保留两边都匹配的键，`left` 保留左表全部行，`right` 与 `outer` 同理。键名不同时用 `left_on` / `right_on`。

`merge()` 默认按列连接，键名可以不同，功能更完整；`join()` 默认按索引连接，适合已经 `set_index()` 的表。

### 5.3 `combine_first()`：互相补齐

```python
filled = source_a.combine_first(source_b)
```

当前表有值时保留当前值，当前表缺失时使用另一张表；两边都缺失则仍为 `NaN`。它适合两份内容几乎相同但缺口互补的数据。

### 5.4 `pivot_table()` 与 `groupby()`

透视表把长表重塑为行列交叉的宽表，四个关键参数是：`index` 定行、`columns` 定列、`values` 定值、`aggfunc` 定算法。

```python
pivot = pd.pivot_table(
    df,
    index="store",
    columns="category",
    values="amount",
    aggfunc="sum",
    fill_value=0,
    margins=True,
)
```

`margins=True` 会添加合计行和列。若需要一次得到多个指标，可使用 `groupby().agg()`：

```python
summary = (
    df.groupby("category", as_index=False)
      .agg(
          order_count=("order_id", "nunique"),
          total_amount=("amount", "sum"),
          average_amount=("amount", "mean"),
      )
      .sort_values("total_amount", ascending=False)
)
```

选型口诀：**结构相同用 `concat`，字段互补用 `merge`，互相补缺用 `combine_first`，换个观察视角用 `pivot_table`。**

### 6.2 综合练习代码

```python
from pathlib import Path
import pandas as pd
import matplotlib.pyplot as plt

DATA = Path("data/sales_2026.csv")
OUT = Path("output")
OUT.mkdir(exist_ok=True)

# 1. 读取与概览
df = pd.read_csv(DATA, encoding="utf-8-sig")
print("原始形状:", df.shape)
display(df.head())
df.info()

# 2. 类型统一：日期、金额、分类
df["order_time"] = pd.to_datetime(df["order_time"], errors="coerce")
df["amount"] = pd.to_numeric(
    df["amount"].astype("string").str.replace(",", "", regex=False),
    errors="coerce",
)
df["category"] = df["category"].astype("category")

# 3. 量化缺失并处理
missing = df.isna().sum().sort_values(ascending=False)
print("缺失值统计:\n", missing[missing.gt(0)])
df = df.dropna(subset=["order_time", "amount"])
df["store"] = df["store"].fillna("未知")

# 4. 去重并重建索引
if "order_id" in df.columns:
    df = df.drop_duplicates(subset="order_id", keep="last")
df = df.reset_index(drop=True)

# 5. IQR 标记异常值，并保留一份截断版本进行对比
q1, q3 = df["amount"].quantile([0.25, 0.75])
iqr = q3 - q1
lower, upper = q1 - 1.5 * iqr, q3 + 1.5 * iqr
df["is_outlier"] = ~df["amount"].between(lower, upper)
df_capped = df.copy()
df_capped["amount"] = df_capped["amount"].clip(lower, upper)
print("异常值数量:", int(df["is_outlier"].sum()))

# 6. 按月和星期统计订单量、销售额
df["month"] = df["order_time"].dt.to_period("M").astype(str)
df["weekday"] = df["order_time"].dt.day_name()
monthly = df.groupby("month", as_index=False).agg(
    order_count=("order_id", "nunique"),
    total_amount=("amount", "sum"),
)

# 7. 门店 × 类别透视表
pivot = pd.pivot_table(
    df, index="store", columns="category", values="amount",
    aggfunc="sum", fill_value=0, margins=True,
)
display(monthly)
display(pivot)

# 8. 可视化并保存结果
monthly.plot(x="month", y="total_amount", marker="o", title="月度销售额")
plt.tight_layout()
plt.savefig(OUT / "monthly_amount.png", dpi=150)
plt.show()

df.to_csv(OUT / "clean_sales.csv", index=False, encoding="utf-8-sig")
pivot.to_excel(OUT / "sales_pivot.xlsx", sheet_name="门店类别", index=True)
```

## 7. 易错点

- 中文 CSV 报错时先检查 `encoding` 和 `sep`，不要盲目修改数据内容；
- `to_csv()` / `to_excel()` 忘记 `index=False` 会多出一列行号；
- `read_excel(sheet_name=None)` 返回字典，不是单个 `DataFrame`；
- 含 `NaN` 的浮点列不能直接转 `int64`；
- 缺失值处理前要先看缺失比例和缺失机制，不能默认全部删除；
- 异常值不等于错误值，删除前应结合业务语义；
- `concat(axis=1)` 按索引对齐，`merge()` 按键对齐；
- `merge(how="inner")` 可能丢失未匹配记录，合并后必须复核行数；
- `replace` 写入数据库会删除旧表，生产环境通常优先考虑 `append`；
- `pivot_table()` 是重塑数据视角，不等同于按主键合并。
